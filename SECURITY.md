# Security Policy (ArmstrongLogic)

## Supported Versions
Only the latest 2026-tier logic gates are supported.

| Version | Supported          |
| ------- | ------------------ |
| v4.4.x  | :white_check_mark: |
| < v4.0  | :x:                |

## Reporting a Vulnerability
If you identify a logic gap or a hardware bypass, do not open a public issue. 
Please signal the Architect via the sovereign communication channels. 
We prioritize zero-day mitigation on all M-series nodes.
